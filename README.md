# neptune-db
Library to connect to proprietary datastores

To run the library, follow the following steps:
1) pip install git+https://github.com/mrajancsr/neptune-db
2) make a environment variable named ARESSQLCONFIGPATH
   that points to location of sql_config dir
3) Retrieve timescale.epm from https://www.notion.so/AWS-TimeScale-Login-796c6c3a6fdf4bd78feeb55f084e1e24
4) Ensure timescale.pem is located in users Home dir
